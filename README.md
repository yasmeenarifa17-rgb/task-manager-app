# Task Manager App

A secure full-stack Task Management Web Application built using React, Firebase Authentication, Firestore Database, and Tailwind CSS.

## Live Demo

https://task-manager-app-ten-beta.vercel.app/

## Features

- User Authentication
- Add Tasks
- Update Task Status
- Delete Tasks
- Real-Time Firestore Updates
- User-Specific Tasks
- Protected Dashboard
- Responsive UI

## Technologies Used

- React
- Vite
- Firebase
- Firestore
- Tailwind CSS
- React Router DOM
- Vercel

## Deployment

Live deployment available on Vercel.
